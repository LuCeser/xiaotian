## What to build

重复上传同一页或导入其他教材中的相同词时，家长看到合并结果和释义差异；系统保留课次关联与学习历史，并正确判断练习资格。

验收共用已确认的测试边界：浏览器操作连接隔离真实应用与测试数据库；仅外部识别／生成服务可用固定响应回归。写入、选题与学习记录须验证真实业务结果；相关真实材料／设备验收随任务完成，不留一个最后才开始测试的任务。

规格故事覆盖：US-31、US-32、US-33、US-34、US-35、US-45。未单列的既有产品规则继续遵守父规格。

## Acceptance criteria

- [x] 同一词条和释义的重复导入不创建新的学习历史，重复提交不会重复写入。
- [x] 同一词保留多个材料和课次来源；至少一个所属课次已学完即可参与，不被其他未学来源阻止。
- [x] 相同词面但释义不同的候选在提交前展示差异，家长确认后处理；未解决差异不静默覆盖原释义。
- [x] 保留家长明确的移出选择，不能通过重复导入补充词汇静默重新开启；课程归属与补充参与的组合规则在本任务实现时明确记录并测试。
- [x] 先定义稳定内容身份、来源关系和释义差异的兼容处理方式，再实施迁移；已有词条标识与学习记录可继续读取。
- [x] 逐项结果区分新增、合并、待处理差异和失败，汇总与实际结果一致。
- [x] 隔离真实服务验证重传、重提、不同来源、不同释义及已有学习历史；课堂选词和后续解释使用确认后的正确教材释义。
