## What to build

家长上传扫描 PDF 后查看各页处理结果，在同一预览中检查词汇与课程归属，批量确认已核对内容，无需拆文件。

验收共用已确认的测试边界：浏览器操作连接隔离真实应用与测试数据库；仅外部识别／生成服务可用固定响应回归。写入、选题与学习记录须验证真实业务结果；相关真实材料／设备验收随任务完成，不留一个最后才开始测试的任务。

规格故事覆盖：US-2、US-4、US-9、US-11、US-13、US-14、US-21、US-45。未单列的既有产品规则继续遵守父规格。

## Acceptance criteria

- [x] 扫描 PDF 可按页识别并复用既有预览、编辑和确认流程，保留结果所属页面及课次。
- [x] 多页结果不乱序、不重复；重复提交沿用既有保护，未来来源合并能力通过统一提交入口生效。
- [x] 处理过程显示状态；页级识别失败、文件无法读取和大小／页数超限给出明确反馈，不伪称全文件成功。
- [x] 可在保留已完成结果的情况下处理失败页；任何未经家长确认的结果不正式入库。
- [x] 适用于整本教材的受控批量处理；本任务依据现有资源约束落实页数、文件限制和任务执行方式，不引入无界内存处理。
- [x] 家长不必为每页重复填写同一本教材的背景信息，可批量调整课次。
- [ ] 使用扫描 PDF、部分页失败和跨课次样例验证入库及实际课堂范围，并在 iPad Safari 检查选文件和长预览操作。
