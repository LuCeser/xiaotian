## Phase Goal

**As a** student using the dictation tutor, **I want to** hear spoken word prompts streamed as audio, **so that** I can practice spelling without reading text.

> Note: ROADMAP Goal is "Real-time TTS audio delivery with <1.5 second latency target" — technical goal, not user-story format. Derived user story above; discrepancy noted for potential `/gsd mvp-phase 6` re-framing.

<objective>
Build the TTS audio foundation layer: configuration, type contracts, MP3-to-PCM codec, and session-level PCM cache. This plan delivers the lowest layer that Plans 06-02 (generator) and 06-03 (streamer) build on.

Purpose: Every downstream TTS component needs (a) typed config for operational tuning, (b) a pure interface contract for testability, (c) a reliable MP3-to-PCM conversion path that works under CGO_ENABLED=0, and (d) a session-scoped cache for PCM files. Without this foundation, the generator cannot produce PCM and the streamer cannot read it.

Output: pkg/tts package with types.go, codec.go, cache.go, doc.go; infra/config.go extended with TTSConfig block. All unit-tested; ffmpeg-dependent paths gated so tests pass on Windows dev hosts without ffmpeg.
</objective>

Create pkg/tts/codec.go with two functions:

1. MP3ToPCM(mp3Path string, opts ConvertOpts) (PCMData, error) — converts an MP3 file to raw PCM using ffmpeg as a subprocess (per Phase 3 D-08: mp3-to-PCM conversion is Phase 6 work). Implementation: call exec.LookPath("ffmpeg") first; if it fails return ErrFFmpegNotFound wrapping the lookup error. Build argv as: ["ffmpeg", "-i", mp3Path, "-f", formatFlag, "-codec:a", codecFlag, "-ar", "16000", "-ac", "1", "-"]. The formatFlag/codecFlag are "s16be"/"pcm_s16be" when opts.BigEndian is true (the default), or "s16le"/"pcm_s16le" when false. Pipe stdout to a bytes.Buffer; stderr to a separate buffer for error diagnostics. Use exec.CommandContext with a context timeout. If exit code is non-zero, return ErrPCMConversionFailed wrapping an error that includes the stderr text. On success, return PCMData{Samples: stdout.Bytes(), FrameSize: 640}. Use argv slice (never shell string) per the same T-03-07 tampering mitigation as pybridge.

2. SliceToFrames(pcm []byte, frameSize int) [][]byte — a pure function that splits a PCM byte slice into consecutive frameSize-byte chunks. The last chunk is right-padded with zero bytes if the PCM length is not a multiple of frameSize (ensures every frame is exactly frameSize bytes for the WS protocol). Empty input returns an empty (non-nil) slice.

Create pkg/tts/cache.go with:

SessionCache struct (fields: baseDir string, logger infra.Logger) managing PCM file storage per D-02/D-08. Constructor NewSessionCache(baseDir string, logger infra.Logger) (*SessionCache, error) — validates baseDir is non-empty, substitutes NoOpLogger for nil.

Methods:
- Store(sessionID string, wordID string, pcm []byte) error — writes pcm bytes to filepath.Join(baseDir, sessionID, wordID+".pcm"). Creates parent directories via os.MkdirAll with 0755 permissions. Returns an error wrapping os.WriteFile failures.
- Load(sessionID string, wordID string) ([]byte, error) — reads filepath.Join(baseDir, sessionID, wordID+".pcm"). If the file does not exist (os.IsNotExist), returns ErrWordNotCached. Otherwise returns the file bytes.
- SessionDir(sessionID string) string — returns filepath.Join(baseDir, sessionID). Used by the generator to pass the output directory to pregenerate.
- Cleanup(sessionID string) error — removes filepath.Join(baseDir, sessionID) via os.RemoveAll. Idempotent: returns nil if the directory does not exist.
- CleanupStale(maxAge time.Duration) error — walks baseDir, removes session subdirectories whose modification time is older than maxAge. Uses filepath.WalkDir for efficiency. Errors removing individual directories are logged but do not stop the walk (best-effort cleanup per D discretion: "session directory cleanup 30 minutes after session ends").

All file paths use filepath.Join (OS-agnostic; works on both Linux VPS and Windows dev). The cache performs no PCM validation — it stores and retrieves raw bytes. PCM format validation is the codec's responsibility.
