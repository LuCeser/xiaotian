## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Session event channel ← Router/handlers | Client control frames arrive via the events channel; malformed events are dropped (not fatal). |
| Deferred cleanup ← cancelled context | The run-loop ctx is cancelled before defer fires; the defer MUST use a fresh ctx (Pitfall 1). |
| Sweeper goroutine ← Manager map | The sweeper reads sessions under RLock and calls cancel(); it must not deadlock against an exiting session's map removal. |
