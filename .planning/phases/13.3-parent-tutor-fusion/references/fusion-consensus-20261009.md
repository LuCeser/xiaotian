# 家长端融合——拷问定案共识（2026-10-09）

本文是 Phase 13.3 的决策记录：一次 grill 讨论走完整棵决策树后，用户对七个分叉逐一拍板的结果。供 /gsd-plan-phase 13.3 直接消费；与 [codex 交互评审](review-parent-tutor-fusion-20261009.md)（同日委托，Orca worktree `review-parent-tutor-fusion` 产出，原样收录）互为参照——评审提供了三种形态与盲区清单，本文记录用户最终选择与偏离。

## 背景事实（讨论起点，已核实）

- 三个互不相通的入口：`/`（Phase 8 旧听写页，被冻结为 RT-10 降级备用，不是空壳）、`/tutor/`（13.1 三段式课堂，学生模式默认，无跨页导航）、`/parent.html`（Phase 9 词库管理，受 v1.0 D-04 约束：URL-only、孩子界面无管理入口、明确拒绝 PIN）。
- 学习数据已落库（lessons 有逐词判定/提示/未核对，practice_logs 有加练记录），缺的是查询投影、家长界面与诚实的保存回执——不是从零开始。
- 家长「看进度、反馈驱动 FSRS」的核心价值只剩课内检查一环；D-12「练习记录家长可查」无界面。
- codex 评审纠正过的三个易错判断：①旧页是完整降级备用，首页不能覆盖 `/`；②tutor 页内有结束/再练一组，缺的只是跨页导航；③`submitted ≠ 已写入 FSRS`（先记阶段再写 FSRS，review_logs 无 lesson_id 无法事后对账）。

## 七项拍板决策

| # | 分叉 | 决策 |
|---|---|---|
| 1 | 交互形态 | **A：统一首页、两扇门、课堂内不切角色**（否决 B 单应用切角色——要动实时课堂生命周期；C 分设备只作兜底形态） |
| 2 | 门禁 | **无 PIN、无权限管理**（用户立场：单家庭一个孩子，防的是「不方便」不是「防孩子」；孩子能加词能看词库都不算问题）。D-04 修订为：废除 URL-only、管理入口可被发现、无门禁；「课堂内无管理操作」目的保留 |
| 3 | 防手滑两条 | **都留**：①进行中课次的成果接口只给日期/词数/阶段，不返回未揭示词（「此刻正在默的词」偷看价值高一个量级）②生产环境服务端强制 student 模式，`mode=test` 仅本机放行 |
| 4 | 切片 | 完整 A 减门禁：成果可读＋保存回执＋home.html＋tutor 回首页；不含任何权限/部署工作 |
| 5 | 排期落位 | 融合＝新阶段 **13.3，纯本地**（开发本机、验收＝家里真 iPad 连本机 HTTPS `run.ps1 -Https` 8443）；复刻 13.1「先本地人工验收」模式 |
| 6 | VPS/13.2 | **搁置**（不删除）：本地即真机，家庭试用场景不需要；重启触发＝离家可用/7×24 在线；重启时按当期 main 重规划 |
| 7 | 10-21 checkpoint | 重定目标为「**13.1＋Phase 13 本地真机验收**」，Plan B 纪律保留，证据口径从公网改为家里局域网；防止到期冒出假警报或留下僵尸条款 |

## 13.3 交付范围（与 ROADMAP 条目一致）

1. 持久保存回执（Go 侧小表）：正常检查/未核对兜底/事后修正/加练各记一次——课次 ID、幂等键、类型、实际 Requested/Updated/Missing 集合或计数、状态、完成时间；崩溃边界显示「待核实」，历史无回执显示「保存状态未知」。
2. `GET /api/v1/lessons`（最近课次，有界分页，含加练）＋ `GET /api/v1/lessons/{id}`（逐词详情）；Go 直读 SQLite，读路径不启 Python；进行中课次不返回未揭示词。
3. parent.html「学习记录」默认标签：最近 20 课＋竖排逐词详情；如实区分课内判定/未核对/提示次数/加练（不进 FSRS）/真实保存状态；正确率分母不含未知词。
4. `/home.html` 家庭首页：两扇门，`/` 原样保留 RT-10 降级备用。
5. tutor 终结态「回首页」：仅在课真正结束、总结播完、音频释放后出现。
6. 生产强制 student 模式。
7. 家庭旅程本地真机验收：家长加词→孩子三段课→关页→家长重开看同一课。

## 明确砍掉

PIN/会话/接口权限/锁定交接 · 家长改评级（Phase 15）· 跨日任意旧课恢复与保存对账（Phase 15）· 完整对话回放（trace 是 200 行 DOM，课关即失，且存在跨课混合风险——回放需独立持久化设计，另议）· 照片/音频归档 · 趋势与掌握度统计 · 指定单元/刚加词立即开课（FSRS 到期选词是既定口径，加词不等于指定下一课）· 多孩子多家长账号 · SPA/CSS 合并 · 根路由迁移 · 一切 VPS 部署动作。

## 评审采纳与偏离说明

- **采纳**：形态 A 框架、成果数据合同（4.1～4.3 节）、「三条事实必须可见：孩子课内判定/家长是否复核/结果是否真的写入」、对话回放后补、加词不等于指定下一课的提示口径。
- **偏离**：评审推荐服务端 PIN 门禁与锁定交接——用户以信任模型（防不方便≠防孩子）明确拒绝，改无门禁 + 两条防手滑；评审建议「10-21 前融合让位真机闭环」——用户以「本地即真机、13.2 搁置」重构了前提，融合升为 13.1 验收后的直接下一阶段。
- **工作量口径**：评审估完整 A 含门禁 5～9 个工作日；砍门禁后约 3～5 个工作日。
