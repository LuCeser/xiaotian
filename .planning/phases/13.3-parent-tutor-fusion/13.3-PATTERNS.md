## Pattern Assignments

### 1. `pkg/lesson/receipt_store.go`（repository，两阶段写 CRUD）[新]

**先例:** `pkg/lesson/practice_store.go`（全文已读）——结构逐项照抄：

**Imports 与构造器**（practice_store.go:13-77）：`context`/`database/sql`/`errors`（github.com/pkg/errors）/`pkg/infra`；构造器 nil-guard db、nil logger→`infra.NewNoOpLogger()`、sentinel `ErrInvalidLesson`（lesson 包已有）：

```go
func NewPracticeStore(db *sql.DB, logger infra.Logger) (*PracticeStore, error) {
	if db == nil {
		return nil, errors.Wrap(ErrInvalidLesson, "lesson/practice_store: *sql.DB must not be nil")
	}
	if logger == nil {
		logger = infra.NewNoOpLogger()
	}
	return &PracticeStore{db: db, logger: logger}, nil
}
```

**DDL 形态**（practice_store.go:26-42）——回执表 DDL 照此写（`CREATE TABLE IF NOT EXISTS`＋显式索引＋显式列常量，**永不 SELECT ***）：

```go
var practiceLogsDDL = `CREATE TABLE IF NOT EXISTS practice_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    lesson_id TEXT NOT NULL,
    ...
    reviewed_day TEXT NOT NULL DEFAULT ''
)`
var idxPracticeLogsDay = `CREATE INDEX IF NOT EXISTS idx_practice_logs_date ON practice_logs(reviewed_day)`
const practiceLogsColumns = "lesson_id, word, rating, correct, hints, reviewed_at, reviewed_day"
```

**写路径**（RecordPractice，84-132）：`BeginTx`＋`defer tx.Rollback()`＋错误时 `s.logger.Error(..., infra.F(...), infra.ErrField(err))`＋`errors.Wrap`。回执的两阶段 API（Begin→Complete）拆成两条独立语句即可（各自单行写，无需事务包裹——崩溃语义正是靠「两条之间断开＝pending」实现）。

**查询路径**（ListPracticeWordsOn，138-163）：`QueryContext`＋`defer rows.Close()`＋逐行 Scan＋`rows.Err()`。`ListPracticeByLesson`、按课聚合回执照此。

### 4. `pkg/rt/check.go` ＋ `pkg/rt/practice.go`（改：四终点挂回执）

**先例:** `finishCheckSubmit`（check.go:600-666，已读）——回执两阶段写挂载点就在这个函数的 SubmitReview 前后：

```go
if len(ratings) > 0 {
	// [新] 回执 INSERT status=pending（幂等键=m.RequestID，在 submitCorrections/handleCheckSubmit 调用方可见）
	wres, err := tm.cfg.Words.SubmitReview(ctx, ratings)
	// [新] 回执 UPDATE status=saved/failed ＋ 真实 requested/updated/missing
	switch {
	case err != nil:
		saveFailed = true   // 诚实失败，永不叙事成功
		...
	default:
		updated, missing = len(wres.Updated), len(wres.Missing)
		if updated < requested {
			// 部分保存不是 failed——真实计数随事件走，绝不盲目重试（S-05，641 行注释在案）
			tm.recorder.Emit(EventError, infra.F("code", ErrCodeProviderFailed))
		}
	}
}
```

关键纪律：**回执不驱动任何自动重写**（S-05）；`err==nil 且 updated<requested` 是 saved（带真实 M/N）不是 failed；四终点同构——`finishCorrections`（812-875，幂等键=`lessonID+"-clear-unchecked"` 附近，844）、`uncheckedCloseFallback`（892-948，同步 close 路径，幂等键=`lessonID+"-complete-check"`，907）、`finishPracticeSubmit`（practice.go:392-465，已读——回执 status 判定参照其 `RecordPractice` err 分支；**加练回执语义＝练习存储成功，不是 FSRS 成功**）。

TurnManager 拿到回执 store 的通道：`TurnManagerConfig` 加字段（先例：main.go:616-617 的 `Practice: cardRepo, PracticeStore: practiceStore` 两行 DI）。

## Shared Patterns

### P1. 错误处理与日志（后端全文件）
**Source:** `pkg/web/api/handlers.go:116-143, 277-291` ＋ `pkg/lesson/practice_store.go:117-124`
`errors.Wrap`/`errors.Is` sentinel 分发；handler 层统一 `writeError` envelope（code+message，无堆栈）；仓储层 `s.logger.Error(..., infra.F("component", ...), infra.ErrField(err))`。**Apply to:** receipt_store、lessons 两个 handler、四终点回执错误分支。

### P2. 服务端投影白名单（泄题防线，本阶段最高风险）
**Source:** 判定分支表 `pkg/rt/turn.go:532-553`（唯一权威）；masking 形态参考 `lessonViewStudent` 675-685（但比本阶段规则宽松，**勿混用**）。
白名单：**只有** `stage=='submitted'` 或（legacy `stage==''` 且 `current_index >= len(cards)`）返回词数据；`checking`、`submitted+unchecked 修正中`、其余一律概要（日期/词数/阶段）。服务端序列化层直接不输出字段（JSON 里没有才是没有）。**Apply to:** `GET /lessons` 列表每一行 ＋ `GET /lessons/{id}`；用 turn.go:532-553 分支表做表驱动穷举测试。

### P3. 构造器 DI（D-42）＋签名变更一次改全
**Source:** `pkg/lesson/practice_store.go:69-77`（nil-guard 构造器）；`cmd/service/main.go:678-679`（唯一挂载点）
NewHandler 加参数 → main.go ＋ handlers_test.go 同一任务内全改；TurnManagerConfig 加字段 → main.go rtTurnCfg（598-618）。禁止 nil 依赖凑合。

### P4. SQLite 单连接读纪律
**Source:** `pkg/lesson/practice_store.go:42`（显式列常量，永不 SELECT *）；`pkg/database/db.go:71`（SetMaxOpenConns(1)）
LIMIT 服务端硬 cap、只 SELECT 需要的列、详情一次一行、`defer rows.Close()`。课堂写路径与读查询共享一条连接，读放大直接卡孩子端。**Apply to:** ListLessons/ListPracticeByLesson/回执聚合查询。

### P5. 静态前端纪律（无构建、textContent-only、缓存戳）
**Source:** `pkg/web/static/js/parent-browse.js:28-49`；`parent.html:83-86`（defer 顺序＋`?v=` 戳）
新 JS 文件 IIFE＋window 挂载＋defer 按序加载＋`?v=20261009a` 戳；全文件禁 innerHTML；toast 复用 `__parentToast`。

### P6. 诚实文案（回执状态机）
**Source:** `pkg/rt/check.go:620-643`（「诚实失败，永不叙事成功」＋S-05 不盲目重试注释在案）
四态：saved / failed（保存未完成）/ pending（待核实）/ 无回执（保存状态未知，历史记录）。`updated<requested && err==nil`＝部分保存（saved 带真实 M/N）。文案逐字对 ROADMAP 成功标准 1；家长页**不得出现「请重试」**（对账留 Phase 15）。课内 review_result 照旧服务孩子端，家长端只读回执表。
