## Prerequisite Connection Fix (dev tooling — not part of the committed phase diff)
Real-iPad testing first hit `WebSocket closed: 1006`. Root cause: `ws.allowedOrigins` defaulted to `[localhost, 127.0.0.1]` (config.go:628), and the iPad loading via LAN IP sent `Origin: http://192.168.31.236:8080`, which `CheckOrigin` (server.go:136-160) rejected at the upgrade. Verified fix from the host side (3-way probe): `evil.example.com`→HTTP 403 (enforcement intact), `localhost`→HTTP 101 (accepted), LAN origin accepted. Resolved by:
- `config.yaml` (gitignored, local): added a full `ws:` block with `allowedOrigins: [localhost, 127.0.0.1, 192.168.31.236]` (all sibling fields spelled out at their defaults to avoid any loader zero-value risk).
- `run.ps1` (new, untracked dev launcher): self-contained — loads `.env` (VOLCENGINE_TTS_* secrets) into the process env, stops any existing `:8080` listener, then `go run ./cmd/service -config config.yaml` with stderr+stdout tee'd to `server.log`. The Go service does NOT auto-load `.env` (no godotenv), so this script is what lets the Python TTS subprocess inherit the credentials.

Both are local dev artifacts (no secrets in them); not committed as part of the phase. `run.ps1` is recommended to keep as the canonical local launch entrypoint.

## Bonus P0 Fix Surfaced by the Wave-1 Gate
While gating Wave 1, `go test ./... ` hit `fatal error: concurrent map read and map write` in `pkg/ws.(*Router).worker` (router.go:205). Root cause: `NewRouter` started worker goroutines inside the same loop that populated `r.routes`, so with ≥2 message types an early worker read `r.routes` concurrently with a later iteration's map write. Pre-existing (Phase 07.1 never touched router.go); the new `handlers_test.go` (live router via httptest) was merely a new trigger. Fixed by splitting `NewRouter` into two passes (populate all routes, then start workers) — `d7019d0`, with `TestNewRouter_RoutesPopulatedBeforeWorkers` regression test. `-count=5` stress clean. This would have crashed the production server under the 100-concurrent target.
