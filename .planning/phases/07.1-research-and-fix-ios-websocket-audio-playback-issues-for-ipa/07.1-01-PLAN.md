<objective>
Fix the two backend audio-sequence protocol bugs (D-10 startSeq off-by-one, D-11 per-word sequence reset) and wire the session-level sequence counter's cleanup into session teardown (Pitfall 5). This is the TRACER plan: it proves the protocol-correctness foundation that the frontend Web Audio rewrite (Plan 03) will debug against. Without monotonic cross-word sequences, frontend debugging cannot distinguish audio-scheduling problems from duplicate-sequence problems (research load-bearing order finding #1).

Purpose: Establish a correct, leak-free audio-frame sequence contract before any frontend work touches it.
Output: Updated pkg/tts/streamer.go (seqCounters field + helpers + D-10/D-11 fixes), extended pkg/session teardown hook, updated + new regression tests.
</objective>
