# Phase 13: R0 真机最小闭环 — Context

**Date:** 2026-09-30（2026-10-03 交互模型转向；2026-10-04 同步）
**Status:** In progress — 13-01～13-06 已执行，13-07～13-13 为现行合同
**Milestone:** v2.0 realtime-tutor

## Phase Boundary

以 FSRS 到期词（上限 10，不足取全部，0 词优雅结束）完成真 iPad HTTPS 状态机默写课。产品目标已确认，不重新讨论按钮主交互或托管 RTC 为默认方案。默认自研交互、MiMo ASR/LLM/TTS 各自可替换、WebSocket 成环；pion WebRTC 在 Phase 16 替换。服务端状态机独占课堂节奏，真实幂等推进与学习记录写入在本阶段进入最小环。

## Implementation Decisions

- 独立自然家教入口；旧按钮页仅为标明的备用模式。一次点击用于平台音频授权，之后持续听说，不每句按住。
- ASR 使用 MiMo 整段接口时，由 VAD 切句提交；输出流式不能冒充持续流式输入。开始采集时协商真实采样率和音频格式，不假设 iPad 采集就是 16kHz。
- 传输只负责音频和控制消息，轮次管理负责 VAD、判停、上下文、取消；供应商适配各自实现 ASR/LLM/TTS。保持小模块，不先做通用 RTC 框架。
- 独立课堂状态存于服务端；课堂词来自真实 FSRS 到期获取，上限 10，不足取全部；不依赖整课预生成和 OCR。
- MiMo LLM 仅做意图识别与话术生成，不发起课堂工具、不拥有推进裁量权。确认与 60 秒超时都由服务端状态机调用同一 `pkg/lesson` 写路径；request_id、lesson_id、expected_version 在执行端校验，同请求相同结果且只写一次，不以 LLM 记忆实现幂等。13-02 已交付的工具 wire 支持保留，13-04 的课堂工具运行时路径由 13-08 移除。
- 音频播放不能等整句收齐。打断时立即停播并丢弃旧轮次的缓冲与迟到输出；取消语音生成不撤销已经提交的课堂工具结果。字幕与上下文要反映实际已播放内容。
- 回声是最低真机检查之一：开扬声器播放时，老师不自我打断；学生插话能生效。
- 普通沉默先作为书写时间；每词计时到 60 秒才自动推进，计时前不得因无声跳词。“不会写”先给部分提示，不直接等同于推进。
- 「好了/可以了/下一个」确认推进；重读/慢读、不会写提示、词义解释、暂停/继续均由状态机确定性处理。暂停确认播报结束后页面仍保持暂停，同时继续识别「继续」。
- 自然完结、无到期词说明、书写计时起点与播报后的回声保护均以客户端 `sentence_ack(epoch,sentence_id)` 的实际播放完成证据为准；服务端发完音频不等于学生已经听完。缺失确认必须有有界等待与诚实事件记录，不能靠扩大固定静默窗口代替。
- 完结先写学习记录，再播报总结；以 pybridge `ReviewResult.Updated` 的实际更新集合为准报告成功数，部分或零更新不得冒充全部保存，也不得对已成功项整批盲目重试。

## Acceptance and Evidence

第一周 2026-10-07 闭环，第三周 2026-10-21 未成环切 Plan B，第六周 2026-11-11 延迟未达标切 Plan B。均北京时间当日 23:59，计时从本轮规划 2026-09-30 起，换方案不重置。

必须有真实麦克风、MiMo 三层调用、LLM 意图识别、状态机幂等推进及实际学习记录写入、真 iPad 播放和打断。录制真机流程并保留脱敏时序日志，按 RT 指标记录首个实际播放与播放完成确认；至少 30 次响应/打断样本用于延迟检查，可跨多节、跨多日累计但必须保留进行中状态与失败样本。模拟供应商和单元测试只能作组件证据。

第一周最小环允许性能仍待调优，但不能缺持续听说、真实读写工具和打断。进入 R1 不取消第六周检查，未达标 RT 项不勾选完成。
