新建 protocol.go（包注释写明：/rt 传输层 = JSON 控制（TextMessage）+ 二进制 PCM（BinaryMessage，客户端上行 s16le 16kHz mono；服务端下行 TTS 采样率以 session_ready.tts.sampleRate 声明））。协议常量 `TTSOutputSampleRate = 24000`（godoc 引用 pkg/tts/mimo_synth.go 的结论：MiMo pcm16 实际输出 24kHz regardless of 请求采样率）。

消息结构体（全部带 `json:"..."` 标签与 type 常量字符串）：
1. 客户端→服务端：`SessionInitMsg{Type string, Audio AudioSpec{SampleRate int, Format string, Channels int}}`（type=="session_init"）；`InterruptMsg{Type string, Epoch uint64, LastSentenceID string, PlayedUntilMs int64}`；`SentenceAckMsg{Type string, SentenceID string, Epoch uint64}`；`EndSessionMsg{Type string}`。
2. 服务端→客户端：`SessionReadyMsg{Type, SessionID string, Audio AudioSpec（回显确认值）, TTSSampleRate int, Lesson LessonView{LessonID string, Version int, CurrentIndex int, Words []string}}`；`TurnStartMsg{Type, TurnID uint64, Epoch uint64}`；`TranscriptMsg{Type, TurnID uint64, Text string}`；`TeacherSentenceMsg{Type, TurnID, Epoch uint64, SentenceID, Text string}`（在音频块之前发送，字幕先行）；`AudioStartMsg{Type, TurnID, Epoch uint64, SentenceID string}` / `AudioEndMsg{同 AudioStart}`；`LessonUpdateMsg{Type, LessonID string, Version, CurrentIndex int, RequestID string}`；`InterruptAckMsg{Type, OldEpoch, NewEpoch uint64, LastSentenceID string, PlayedUntilMs int64}`；`StateMsg{Type, Value string}`（"listening"/"processing"/"speaking"）；`ErrorMsg{Type, Code string, Message string, Recoverable bool}`；`SessionEndedMsg{Type, Reason string}`。
3. 错误码常量：`ErrCodeUnsupportedFormat`、`ErrCodeVoiceUnavailable`（无 MIMO_API_KEY）、`ErrCodeProviderFailed`、`ErrCodeMicUnavailable`（客户端上报透传）、`ErrCodeInvalidMessage`、`ErrCodeSessionClosed`。
4. `func ParseControl(data []byte) (any, error)`：Unmarshal 到只含 Type 的探针结构，按 type 反序列化到具体结构体返回；未知 type 返回 ErrCodeInvalidMessage 包装错误；超大消息拒绝由 conn 层负责。
5. `func ValidateAudioInit(a AudioSpec) error`：R0 仅接受 SampleRate==16000 && Format=="s16le" && Channels==1，否则返回携带 ErrCodeUnsupportedFormat 的错误。

protocol_test.go：每个消息类型 JSON 往返（marshal→ParseControl→字段相等）断言字段名与 RESEARCH Pattern 6 示例一致（session_init.audio.sampleRate 等）；ValidateAudioInit 矩阵（合法 / 48000 / "f32le" / 2ch 四种）；未知 type 拒绝。
