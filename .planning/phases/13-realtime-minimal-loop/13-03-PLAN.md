2. 服务端→客户端：`SessionReadyMsg{Type, SessionID string, Audio AudioSpec（回显确认值）, TTSSampleRate int, Lesson LessonView{LessonID string, Version int, CurrentIndex int, Words []string}}`；`TurnStartMsg{Type, TurnID uint64, Epoch uint64}`；`TranscriptMsg{Type, TurnID uint64, Text string}`；`TeacherSentenceMsg{Type, TurnID, Epoch uint64, SentenceID, Text string}`（在音频块之前发送，字幕先行）；`AudioStartMsg{Type, TurnID, Epoch uint64, SentenceID string}` / `AudioEndMsg{同 AudioStart}`；`LessonUpdateMsg{Type, LessonID string, Version, CurrentIndex int, RequestID string}`；`InterruptAckMsg{Type, OldEpoch, NewEpoch uint64, LastSentenceID string, PlayedUntilMs int64}`；`PongMsg{Type, TClientMs int64, TServerMonoNs int64}`（回显客户端时刻 + 服务端单调纳秒——与 rt_event 的 t_mono_ns 同锚，客户端以 RTT/2 估计偏移，13-05 记 clock_offset 事件）；`StateMsg{Type, Value string}`（"listening"/"processing"/"speaking"）；`ErrorMsg{Type, Code string, Message string, Recoverable bool}`；`SessionEndedMsg{Type, Reason string}`。
