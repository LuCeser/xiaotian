<objective>
Implement the connection registry, session-limit enforcement (RES-03, D-56), periodic stale-connection cleanup (D-57), per-connection token bucket throttling (D-66), aggregate metrics (D-61), and lifecycle hooks (D-55). Registry uses a map-based O(1) lookup with RWMutex per D-54. UUID v4 session IDs per D-58. The 100-session hard limit returns ErrTooManyConnections which Plan 08's server translates into HTTP 429.

This plan also encodes the connection-management decisions D-59 through D-67. The registry is the bounded pool per D-63 (map with fixed capacity = pooling/reuse, connections reused via Touch rather than reallocated). Active connections are prioritized over new ones per D-64 (capacity breach rejects the new registration, never evicts an active one). The SessionID lookup is the stateless auth hook per D-65 (registry verifies token presence; cryptographic validation is a Phase 2 caller responsibility). Configurable timeouts per D-59 bound the connection lifecycle (IdleTimeout triggers stale cleanup; DialTimeout bounds outbound dials in future phases). On-accept protocol validation per D-62 surfaces via the OnError lifecycle hook that Phase 2's WebSocket upgrade handler populates. Automatic reconnection with exponential backoff and jitter per D-67 is a client-side concern; this plan delivers the OnDisconnect observation hook the client SDK will consume.

Purpose: Plan 08's server needs to call Register() on every inbound connection and Unregister() on disconnect. Plan 07's worker pool needs the TokenBucket type. The connection contract must be locked here so neither of those plans reshape it.

Output: `pkg/infra/connection.go` (ConnectionRegistry, Connection, LifecycleHooks, TokenBucket, ConnectionStats), `pkg/infra/connection_test.go` with the VALIDATION.md-mandated `TestSessionLimit` test name.
</objective>

    - Validate cfg.MaxConcurrent > 0 (production default 100 per RES-03/D-56).
    - Validate cfg.IdleTimeout > 0, cfg.CleanupInterval > 0.

    Method `(r *ConnectionRegistry) Register() (*Connection, error)`:
    1. Acquire write lock.
    2. If len(r.conns) >= r.limit: release lock, increment totalRejected, optionally call r.hooks.OnError("", ErrTooManyConnections) if non-nil, log Warn "connection rejected (at capacity)" with component=infra.connection fields limit and active, return nil, ErrTooManyConnections.
    3. Generate `id := SessionID(uuid.NewString())` per D-58.
    4. Create Connection with State=StateActive, CreatedAt=time.Now(), LastSeen=CreatedAt.
    5. Store r.conns[id] = conn.
    6. Release lock.
    7. Increment totalAccepted.
    8. Call r.hooks.OnConnect(id) if non-nil.
    9. Log Info "connection registered" with session_id=id, component=infra.connection.
    10. Return conn, nil.

    Method `(r *ConnectionRegistry) Unregister(id SessionID) error`:
    1. Acquire write lock.
    2. If _, ok := r.conns[id]; !ok: release lock, return ErrConnectionNotFound.
    3. Delete r.conns[id].
    4. Release lock.
    5. Call r.hooks.OnDisconnect(id) if non-nil.
    6. Log Info "connection unregistered" with session_id=id.

    Method `(r *ConnectionRegistry) Lookup(id SessionID) (*Connection, error)`:
    1. Acquire read lock.
    2. Defer release.
    3. Return copy of *Connection (or pointer — document immutability contract; safer to return copy).
    4. If not found, return ErrConnectionNotFound.

    Method `(r *ConnectionRegistry) Touch(id SessionID) error`: acquires write lock, updates LastSeen=time.Now(), returns ErrConnectionNotFound if missing.

    Method `(r *ConnectionRegistry) Start(ctx context.Context) error`: spawns cleanup goroutine.
    - If r.running.CompareAndSwap(false, true) fails, return ErrAlreadyRunning.
    - Spawn goroutine:
      ```
      ticker := time.NewTicker(r.cleanupInterval)
      defer ticker.Stop()
      defer r.running.Store(false)
      for {
          select {
          case <-ctx.Done(): return
          case <-ticker.C: r.cleanupStale(ctx)
          }
      }
      ```

    Method `(r *ConnectionRegistry) cleanupStale(ctx context.Context)` (unexported):
    1. Acquire write lock.
    2. Build list of IDs whose time.Since(LastSeen) > r.idleTimeout.
    3. Delete them, count removed.
    4. Release lock.
    5. totalCleaned.Add(uint64(removed)).
    6. Log Warn "stale connections cleaned" with count=removed, component=infra.connection.
    7. For each removed ID, call r.hooks.OnDisconnect(id) if non-nil.

    Method `(r *ConnectionRegistry) Stats() ConnectionStats`:
    1. Acquire read lock; snapshot len(r.conns); release.
    2. Return ConnectionStats{Active: n, TotalAccepted: r.totalAccepted.Load(), TotalRejected: r.totalRejected.Load(), TotalCleaned: r.totalCleaned.Load()}.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Network → ConnectionRegistry.Register | Untrusted remote attempts to open connection; limit is the gate |
| Connection → TokenBucket.Allow | Each remote-initiated operation consumes a token; throttle is the gate |
| Registry cleanup → OnDisconnect hook | Stale connection removal fires hooks; caller-supplied code must be re-entrant |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-22 | Denial of Service | Connection flood exhausts resources | high | mitigate | Hard limit of 100 (D-56, RES-03); 101st registration returns ErrTooManyConnections → HTTP 429. |
| T-01-23 | Spoofing | Session ID collision | medium | mitigate | UUID v4 (D-58) provides 122 bits of entropy; collision probability negligible. |
| T-01-24 | Denial of Service | Stale connection accumulation | high | mitigate | Cleanup routine every 30s (D-57) removes connections idle beyond IdleTimeout. |
| T-01-25 | Denial of Service | Per-connection request flood | medium | mitigate | TokenBucket (D-66) limits each connection to ThrottleRatePerSec operations per second. |
| T-01-26 | Repudiation | Missing connection event trail | low | mitigate | OnConnect/OnDisconnect/OnError hooks + Info/Warn logs with session_id provide audit trail. |
| T-01-27 | Denial of Service | Registry cleanup goroutine leak | high | mitigate | Start honors ctx cancellation; TestRegistryStopsOnContextCancel proves goroutine exits within 200ms. |
