<objective>
Implement the audio buffer pool with drop-oldest overflow strategy (RES-04, D-14, D-71, D-73). The pool wraps sync.Pool for 640-byte buffers (20ms@16kHz PCM, per WebSocket protocol requirement), maintains an atomic counter for in-flight buffers, and drops the oldest buffer (lets GC reclaim it) when an overflow Put arrives at capacity — never crashes, never blocks.

Purpose: Phase 2's WebSocket layer will call BufferGet() on every inbound audio frame and BufferPut() when done. The pool contract must be locked here so Phase 2 doesn't reshape the API. The drop-oldest semantics must also be testable in isolation so RES-04 has a deterministic verification path independent of network code.

Output: `pkg/infra/pool.go` (AudioBufferPool, NewAudioBufferPool, PoolStats), `pkg/infra/pool_test.go` with the VALIDATION.md-mandated `TestDropOldestStrategy` test name.

    Define `AudioBufferPool` struct:
    - `pool sync.Pool` (initialized with New func returning &AudioFrame with cap=AudioFrameBytes)
    - `frameBytes int` (locked to BufferConfig.AudioFrameBytes; default 640 per D-71)
    - `capacity int32` (BufferConfig.PoolSize; max in-flight before drop)
    - `inFlight atomic.Int32`
    - `totalGets atomic.Uint64`
    - `totalPuts atomic.Uint64`
    - `totalDrops atomic.Uint64`
    - `logger Logger`

    Constructor `func NewAudioBufferPool(cfg BufferConfig, logger Logger) (*AudioBufferPool, error)`:
    - Validate cfg.AudioFrameBytes > 0 (production default 640; tests may use smaller values).
    - Validate cfg.PoolSize > 0.
    - Validate cfg.Strategy == StrategyDropOldest (only supported strategy in Phase 1).
    - Initialize pool.New to return `any(&AudioFrame(make([]byte, 0, cfg.AudioFrameBytes)))` — note: `make([]byte, 0, n)` gives len 0 cap n. Cast return value from sync.Pool.Get to `*AudioFrame`.
    - If logger nil, substitute NoOpLogger.
    - Return &AudioBufferPool{...}, nil. Return ErrInvalidBufferConfig on validation failure.

    Method `(p *AudioBufferPool) Get() *AudioFrame`:
    1. `p.inFlight.Add(1)`
    2. `p.totalGets.Add(1)`
    3. `buf := p.pool.Get().(*AudioFrame)` — sync.Pool blocks never; may allocate if empty.
    4. Defensive: if `cap(*buf) != p.frameBytes`, reallocate `*buf = make([]byte, 0, p.frameBytes)` (guards against sync.Pool GC behavior returning unexpectedly resized buffers).
    5. Reset length to 0 (clears any prior data without losing capacity): `*buf = (*buf)[:0]`.
    6. Return buf.

    Method `(p *AudioBufferPool) Put(buf *AudioFrame) error`:
    1. If buf is nil, return ErrNilBuffer.
    2. If cap(*buf) != p.frameBytes, return errors.Wrap(ErrOversizedBuffer, "buffer capacity does not match pool's frame size") — defend against Pitfall 2.
    3. `p.totalPuts.Add(1)`
    4. `current := p.inFlight.Load()`
    5. If `current > p.capacity` (strictly greater means we are already over): drop-oldest per D-73.
       a. `p.totalDrops.Add(1)`
       b. Do NOT call p.pool.Put(buf) — let GC reclaim it (this is the drop).
       c. `p.inFlight.Add(-1)`
       d. `p.logger.Warn("buffer dropped (overflow)", F("component","infra.pool"), F("drops", p.totalDrops.Load()), F("capacity", p.capacity))`
       e. Return ErrBufferDropped (sentinel; lets caller decide whether to log/ignore).
    6. Else: `*buf = (*buf)[:0]` (reset), `p.pool.Put(buf)`, `p.inFlight.Add(-1)`, return nil.

    The `current > p.capacity` check requires that Get always increments inFlight BEFORE the caller uses the buffer, and Put always decrements AFTER. This means inFlight accurately reflects "how many buffers are outside the pool." When inFlight > capacity, dropping the incoming Put (oldest in conceptual FIFO order, since sync.Pool has no FIFO guarantee but the caller just finished using it and can re-acquire via Get if needed) keeps memory bounded.

    Method `(p *AudioBufferPool) Stats() PoolStats` returns a snapshot:
    - InFlight: int64(p.inFlight.Load())
    - Capacity: int(p.capacity)
    - TotalGets, TotalPuts, TotalDrops: load each atomic

    Sentinel errors:
    - `var ErrInvalidBufferConfig = errors.New("invalid buffer pool configuration")`
    - `var ErrNilBuffer = errors.New("buffer is nil")`
    - `var ErrOversizedBuffer = errors.New("buffer capacity exceeds pool's frame size")`
    - `var ErrBufferDropped = errors.New("buffer dropped due to overflow")` — returned to caller on drop; not a panic.

    Document the drop-oldest contract on Put: "If the pool is at capacity, Put drops the supplied buffer (lets GC reclaim it) and returns ErrBufferDropped. The caller may treat this as a soft signal — the buffer is gone, no further action required."

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller → AudioBufferPool.Get/Put | Callers may pass malformed buffers (oversized, nil); Put validates |
| sync.Pool runtime → AudioBufferPool | sync.Pool may clear pooled objects between GC cycles; Get defends by re-checking capacity |
| AudioBufferPool → GC | Dropped buffers become garbage; bounded by capacity so GC pressure stays predictable |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-18 | Tampering | Buffer overflow via large payloads | high | mitigate | Put rejects buffers whose cap != frameBytes (640); defensive reallocation in Get if sync.Pool returns unexpected size. |
| T-01-19 | Denial of Service | Pool exhaustion / OOM under burst | high | mitigate | Drop-oldest at capacity (RES-04): overflow Puts return ErrBufferDropped, GC reclaims, memory bounded by PoolSize × frameBytes. |
| T-01-20 | Tampering | Caller puts nil buffer | low | mitigate | Put returns ErrNilBuffer on nil input; counter untouched. |
| T-01-21 | Information Disclosure | Stale buffer data leaks between callers | medium | mitigate | Get always resets len to 0; Put resets len to 0 before returning to pool. TestBufferPoolPutResetsLength proves it. |
</threat_model>
