## Pattern Assignments（逐文件应抄的模式）

### 1. `pkg/rt/dictation.go` — 检查评级（checkRating）＝ wordRating 的兄弟函数

**参照：** 同文件 `wordRating`（:97-135，U-9 已落码），注释是纪律原文——「13.1 must not fork a second matrix… this (outcome, hints) signature is the entire reserved seam」。

```go
// Source: pkg/rt/dictation.go:116-135
func wordRating(outcome string, hints int) string {
	switch outcome {
	case outcomeConfirmed:
		if hints > 0 { return ratingHard }
		return ratingGood
	case outcomeTimeout:
		if hints > 0 { return ratingAgain }
		return ratingHard
	case outcomeHint:
		return ratingAgain
	default:
		return ""
	}
}
```

**新写法要点（规划据此展开）：**
- `checkRating(result, hints)` 是新的表驱动纯函数，紧挨 wordRating 放置，共用 `ratingGood/ratingHard/ratingAgain` 常量（:91-95）；检查结果用新常量族（仿 :82-87 的 outcome 常量写法）。
- D-03 未核对兜底**调用** wordRating 后整体降一档（good→hard、hard→again），写成独立小函数＋单测，不在矩阵里加行。
- 打码模板仿同文件 `announceText`（:503-513）纯函数模式：学生模式选 masked 变体（「第 N 个词。」），TTS 仍读原词。
- 逐词行为字段仿 `perWordOutcome/perWordHints`（:189-190）声明在 `DictationTutor`（单锁纪律：全部由 TurnManager 的 mu 守护，:180-183）。

### 2. `pkg/rt/turn.go` — checking 阶段接入

**参照：** 自身既有 dispatch/announce 路径。硬性约束（研究 Pitfall 9）：
- 逐词引导播报复用 `runAnnouncement`/`awaitPlaybackCompletion`（turn.go:577-597 附近，ack 驱动 settle），**必须过 sentence_ack 门**。
- 顺序固定：改判收敛 → `SubmitReview`（一次）→ 战果总结 → `session_ended(lesson_complete)`。
- 统一提交复用如实报告分支（turn.go:1106-1131）：

```go
// Source: pkg/rt/mimo_adapters.go:246（契约）
```

- 恢复路径改造点：`startCompletedSession` 短路处（turn.go:451-452，`CurrentIndex >= len(Cards)` → ready＋ended）前先查课行「未核对」标记 → 进检查恢复而非短路结束。
