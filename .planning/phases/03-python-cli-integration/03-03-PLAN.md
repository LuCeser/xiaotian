## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Go service → Python subprocess | exec.CommandContext 跨进程边界，argv/env 跨越此线 |
| Python stdout/stderr → Bridge.run | 子进程输出（可能含非预期字节）进入 Go 内存 |
| Bridge → infra.Logger | 错误/诊断信息写入结构化日志（操作者可读） |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
