<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem → Open() | Operator-supplied dbPath crosses into process (directory creation) |
| Go process ↔ Python process | Shared SQLite file; write separation is the trust boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05 | Denial of Service | Open without busy_timeout | high | mitigate | DSN pins busy_timeout=5000; TestOpen_Pragmas asserts the value (RESEARCH Pitfall 2) |
| T-04-06 | Tampering | Migrate alters Python tables | high | mitigate | Migrate issues DDL only for sessions/session_events; migrate_test asserts sqlite_master table set is exactly the Go-owned pair (D-01/D-02) |
| T-04-07 | Tampering | DSN format mismatch silently disables pragmas | medium | mitigate | TestOpen_Pragmas queries PRAGMA journal_mode/busy_timeout/foreign_keys rather than trusting the DSN string (RESEARCH Pitfall 3) |
| T-04-08 | Information Disclosure | Unclosed WAL files on shutdown | low | mitigate | Open doc states caller owns Close(); Plan 05 wires db.Close() into the shutdown sequence (RESEARCH Pitfall 6) |
</threat_model>
