## WebSocket库选择

| Option | Description | Selected |
|--------|-------------|----------|
| gorilla/websocket | 成熟稳定，广泛使用，有良好的Safari兼容性记录。性能稍逊但可靠性高，适合生产环境。 | ✓ |

**Notes:** 用户优先考虑稳定性和Safari兼容性，这对iPad浏览器环境至关重要。
