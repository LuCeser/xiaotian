实现 Router struct（实现 FrameHandler 接口，PATTERNS.md 第 494-506 行）：
- routes map[MessageType]chan frameTask
- handlers map[MessageType]Handler
- wg sync.WaitGroup（每个 MessageType 启动 WorkerConcurrency 个 worker goroutine）
- mu sync.RWMutex（保护 handlers 注册）

定义内部 frameTask struct：{ ctx context.Context; client *Client; header *FrameHeader; payload []byte }

实现 NewRouter(handlers map[MessageType]Handler, cfg RouterConfig, logger *zap.Logger) (*Router, error)（D-42 + D-44）：
- 校验 cfg、nil 替换 logger
- 为每个 MessageType 创建 make(chan frameTask, cfg.RouteBuffer)
- 启动 cfg.WorkerConcurrency 个 worker goroutine per MessageType（D-16 worker pool for logic）
- 每个 worker：for { select { case task := <-r.routes[mt]: 调用 handler 并 panic recovery (D-49)；case <-ctx.Done(): return } }
- 返回 *Router

实现 (r *Router) Route(ctx context.Context, c *Client, h *FrameHeader, payload []byte) error（FrameHandler 接口实现）：
- r.mu.RLock(); handler, ok := r.handlers[h.MsgType]; r.mu.RUnlock()
- if !ok → return errors.Wrap(ErrUnknownMessageType, fmt.Sprintf("msg type 0x%02x", h.MsgType))
- task := frameTask{ctx, c, h, payload}
- select {
    case r.routes[h.MsgType] <- task: return nil  // 成功入队
    case <-r.ctx.Done(): return ErrRouterShuttingDown
    default: return ErrRouterOverloaded  // D-73 drop-oldest 背压
  }
- 关键：使用 select default 实现 non-blocking 投递，channel 满时立即返回 ErrRouterOverloaded（drop-oldest 而非阻塞 readPump）

实现 worker（私有方法 (r *Router) worker(mt MessageType, handler Handler)）：
- defer r.wg.Done()
- for { select {
    case task := <-r.routes[mt]:
        func() {
            defer func() { if rec := recover(); rec != nil {
                r.logger.Error("handler panic recovered", zap.String("component", "ws.router"), zap.String("msg_type", mt.String()), zap.Any("recovered", rec), zap.Stack("stack"))
            } }()
            if err := handler(task.ctx, task.client, task.header, task.payload); err != nil {
                r.logger.Warn("handler returned error", zap.String("msg_type", mt.String()), zap.Error(err))
            }
        }()
    case <-r.ctx.Done(): return
  } }

实现 (r *Router) Close()：调用 r.cancel()，r.wg.Wait()（等待所有 worker 退出，D-12 清理）

**关键设计决策：**
- Router 不依赖 Phase 1 pkg/infra/worker.go（Plan 07 未交付），自包含 worker goroutine —— 对齐 RESEARCH.md Open Question 3 自包含路径

- Handler 内禁止直接调用 client.conn.WriteMessage；必须通过 client.send <- msg 让 writePump 串行化（RESEARCH.md Pitfall 3）
