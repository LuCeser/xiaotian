- if len(data) < HeaderSize → return false

实现 EncodeFrame(h *FrameHeader, payload []byte) []byte（PATTERNS.md 第 180-186 行）：
- 设置 h.PayloadLen = uint16(len(payload))（D-09 变长字段自动填充）

- copy(buf[:HeaderSize], header)、copy(buf[HeaderSize:], payload)
- 返回 buf

实现 DecodeFrame(raw []byte) (*FrameHeader, []byte, error)：
- if !ValidateFrame(raw) → return nil, nil, ErrCRCChecksumFailed（T-02-01 防篡改）

- payload := raw[HeaderSize:]
