**Target extension** (per RESEARCH §"Emission Sites & Ordering Invariant" lines 311-332). Capture `wordIndex` under the existing lock; replace the bare `if` with a `switch`:

```go
func (s *Session) onTransition() {
    s.mu.Lock()
    s.deadline = time.Now().Add(s.timeoutFor(s.state))
    newState := s.state
    wordIndex := s.wordIndex // capture under lock (D-04)
    s.mu.Unlock()

    s.auditState(newState)

    switch newState {
    case database.StateListening:
        // D-04: emit progress_update BEFORE streaming so the frontend sets
        // currentWordId before this word's audio frames arrive.
        s.emitProgressUpdate(wordIndex)
        s.spawnStreamWord()
    case database.StateWaitingParent:
        // D-06: last word done → session_complete. No new terminal state.
        s.emitSessionComplete()
    }
}
```

**Ordering invariant (critical):** `emitProgressUpdate` MUST run synchronously *before* `spawnStreamWord()`. Proof: `emitProgressUpdate` calls `s.client.Send(frame)` → FIFO client send-channel; `spawnStreamWord` then spawns a goroutine (`session.go:375`) whose first audio-frame `client.Send` can only happen after goroutine scheduling + `StreamWord` PCM load — strictly later. Both frames hit the **same** FIFO channel, so wire order = `progress_update` → audio. ✓ **Do not** emit from inside the goroutine or after.

**Analog 2 — the routing key (word_id source):** `pkg/session/session.go:371` (verbatim):

```go

```

This is the same value `spawnStreamWord` passes to `streamer.StreamWord(ctx, s.client, s.id, wordID, 0)` (line 377) and the same value the streamer's `sendWordComplete` emits as `{"type":"word_complete","word_id": wordID}`. **`progress_update.word_id` MUST be `s.wordQueue[wordIndex].Word`** (the word string) so all three frame families key identically and the frontend's `pendingPcm.get(wordId)` lookup resolves. // emitControl builds a JSON control frame and sends it via s.client. Nil-safe
// (tests pass nil client). Mirrors cmd/service sendControlFrame. Uses
// Sequence: 0 — the frontend dispatches control frames by JSON type, not
// sequence (audio-controller.js:147-153 dedups only audio).
func (s *Session) emitControl(msgType ws.MessageType, payload interface{}) {
    if s.client == nil {
        return
    }
    b, err := json.Marshal(payload)
    if err != nil {
        s.logger.Warn("session: failed to marshal control frame",
            infra.F("component", "session"),
            infra.F("session_id", s.id),
            infra.ErrField(err),
        )
        return
    }
    frame := ws.EncodeFrame(&ws.FrameHeader{
        Version:  ws.ProtocolVersion,
        MsgType:  msgType,
        Sequence: 0, // control frames not deduped by sequence on the frontend
        PayloadLen: uint16(len(b)),
    }, b)
    if err := s.client.Send(frame); err != nil {
        s.logger.Warn("session: failed to send control frame",
            infra.F("component", "session"),
            infra.F("session_id", s.id),
            infra.ErrField(err),
        )
    }
}

This is the proof the ordering invariant holds.
