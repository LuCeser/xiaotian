<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iPad Safari browser → Go backend | Untrusted client input crosses WebSocket connection |
| Static file serving → Client | Server-provided HTML/JS executes in client context |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Spoofing | WebSocket connection | medium | mitigate | Origin validation via CheckOrigin (already in Phase 2 server.go) |
| T-08-02 | Tampering | Static file serving | low | accept | Read-only static files, no user input processed |
| T-08-03 | Information disclosure | File system traversal | low | mitigate | http.FileServer restricts to static directory, validate path in config |
| T-08-04 | Denial of Service | WebSocket reconnection flood | medium | mitigate | Max reconnect attempts (10) in client, connection limits in server (Phase 1) |
</threat_model>
