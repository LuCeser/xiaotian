# Phase 9 — UI Design Contract

> Visual and interaction contract for the parent vocabulary management page
> (`parent.html`). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> All UI copy is zh-CN plain language for a non-technical parent (CONTEXT
> specifics + D-15). Rows marked **(auto-decided)** were chosen autonomously
> in yolo mode where upstream artifacts left discretion.

## Spacing Scale

Declared values (multiples of 4 only). Base `font-size: 100%` (16px), rem
units, same convention as `main.css`.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon/glyph gaps, badge inner padding |
| sm | 8px | Compact element spacing, chip gaps, row meta gaps |
| md | 16px | Default element spacing, card inner padding (mobile), form field gaps |
| lg | 24px | Card inner padding (≥768px), section padding |
| xl | 32px | Between cards, toolbar-to-list gaps |
| 2xl | 48px | Major section breaks (header → first card) |
| 3xl | 64px | Page-level top/bottom breathing room (desktop) |

Exceptions (auto-decided, all multiples of 4):
- Touch targets: **44px minimum** height for all buttons, inputs, filter
  pills, and unit-group headers (iOS HIG; parent uses the same iPad).
- Unit-group header row: 48px (taller than 44px — it is the primary
  scan-and-tap row of the browse view).
- Modal max-width: 480px; preview table max-height 320px then scrolls.

## Typography

Exactly 4 sizes, exactly 2 weights (400 regular + 600 semibold). System font
stack above. **(auto-decided)** — no webfont: no build step, no external
requests from the family VPS, and PingFang SC on iPad is the native face the
parent already reads everywhere.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 | Inputs, table rows, buttons, toasts (16px minimum defeats iOS zoom-on-focus) |
| Label | 14px | 600 | 1.4 | Form labels, unit counts (`12 个单词`), badges, meta text, slider readouts |
| Heading | 20px | 600 | 1.2 | Card titles (添加单词 / 浏览词库 / 学习设置), unit-group headers, modal titles |
| Display | 28px | 600 | 1.2 | Page title `单词库管理` only |

Muted text uses Body at 14px/400 (`#6b7280`) for hints and subtitles — a
size/weight combination, not a fifth role.

Accent reserved for (explicit, exhaustive):
1. Primary action buttons: `添加单词`, `确认添加`, `保存设置`

6. Slider track fill (FSRS settings)

Category data-coding (reuses existing student state tokens — not new
colors): english badge `#dbeafe` bg / `#1e3a8a` text; chinese badge

## Layout & Page Structure

Page identity: header carries only `单词库管理` + subtitle
`添加、整理孩子的听写词库` — **no navigation, no link from the student page**
(D-04; URL-only access). No connection indicator (REST page, not a live
session).

Section order (mobile = DOM order):
1. Header
2. `添加单词` card — tabs `单个添加 | 批量添加` (D-10 dual entry)
3. `浏览词库` card — toolbar (search + category pills) + collapsible unit
   groups (D-12)
4. `学习设置` card — embedded, NOT a separate page (D-15)

Focal point (浏览词库): the unit-group list; page anchored by the Display
title `单词库管理`; `添加单词` CTA is the single most saturated element
above the fold.

Responsive structure **(auto-decided)**:
- **<1024px:** single column, sections stacked in DOM order.
- **≥1024px:** two-column grid — main column `浏览词库` (2fr), right rail
  `添加单词` + `学习设置` (1fr); container max-width 1120px, centered.
  Rationale: browse/organize is the wide-table task; add/settings are
  narrow-form tasks.

Card anatomy: white surface, `border-radius: 16px`, `border: 1px solid
#e5e7eb`, padding 16px (mobile) / 24px (≥768px), cards separated by 32px.
Flat — no drop shadows except the modal overlay (management-tool calm, not
kid 3D).

## Interaction & Motion

- **Add (single):** validate 单词 non-empty + category chosen → `POST
  /api/v1/words` → success toast + form clears (category/unit retained for
  rapid consecutive entry — auto-decided) → browse refreshes.
- **Add (batch, D-10):** paste → `解析并预览` (client-side pure parser,
  node-testable) → preview table with per-line errors → `确认添加（{n} 个）`
  disabled when 0 valid rows → result banner `已添加 {a} 个，跳过 {b} 个重复
  单词` (Pitfall 3: prominent, Warning color when b>0) → browse refreshes.
  The 单元 field + datalist applies to the whole pasted batch (one lesson =
  one unit; D-10 / RESEARCH Pitfall 4 semantics); per-word unit changes
  afterwards go via 编辑.
- **Search:** 300ms debounce → `GET /api/v1/words?q=` (server-side LIKE,
  RESEARCH). Clear button restores full list.
- **Edit:** row `编辑` → modal (category read-only — `edit` only updates
  word/meaning/example/unit, D-07) → `PUT /api/v1/words/{id}` → toast.
- **Delete:** word row `删除` or unit header `删除` → destructive confirm
  modal showing exact count → `DELETE /api/v1/words` (always `--confirm`
  server-side, Pitfall 1; UI owns the dialog).
- **Rename:** unit header `重命名` → modal → `POST /api/v1/units/rename` →
  on "unit not found" show Error toast with the backend message (Pitfall 2).
- **Settings:** sliders update readout live; `保存设置` → `PUT
  /api/v1/settings/fsrs` → toast `已保存，下次听写生效`; `恢复默认` resets
  sliders to 0.85 / 180 (does not save until `保存设置`).
- **Motion:** transitions ≤200ms ease-out (press feedback, collapse
  height, modal fade). One animation budget — no decorative motion.
  `prefers-reduced-motion: reduce` disables all of it (student CSS
  precedent).

## Responsive Behavior

Mobile-first `min-width` media queries (same approach as `main.css`).

| Breakpoint | Layout |
|------------|--------|
| <768px (phone) | Single column; card padding 16px; toolbar stacks (search full-width, pills wrap); word rows stack meaning under word |
| 768–1023px (tablet/iPad) | Single column; card padding 24px; toolbar one row; word rows single-line |
| ≥1024px (desktop) | Two-column grid (browse 2fr / rail 1fr), max-width 1120px |

Global: `touch-action: manipulation`, `-webkit-tap-highlight-color:
transparent`, inputs ≥16px (no iOS zoom-on-focus). Viewport meta mirrors
index.html.

## Accessibility Contract

- 44px minimum touch targets everywhere (parent shares the iPad).
- `:focus-visible` 3px accent outline, 2px offset (student CSS precedent).
- `aria-live="polite"` on toast region and browse list region.
- Modals: `role="dialog"`, `aria-modal`, focus trap, Esc, labelled by title.
- Unit groups: `<button>` headers with `aria-expanded`.
- Color never the only signal: category badges carry text; added/skipped
  counts carry numbers; destructive actions carry explicit copy.
