- 第 208 行：`started := waitForGoroutineIncrease(baseGoroutines, 500*time.Millisecond)` → 把 `500*time.Millisecond` 改为 `2*time.Second`。
- 第 218 行：`waitForGoroutineDrain(baseGoroutines+1, 500*time.Millisecond)` → 把 `500*time.Millisecond` 改为 `2*time.Second`。
- helper 函数 waitForGoroutineIncrease（第 323 行）与 waitForGoroutineDrain（第 337 行）的签名与实现**不动**。
- 只改这两个调用点的实参；不要动文件里其他 time.Sleep（如第 88/119/176/274/313 行）——诊断只锁定 208/218。

- `go vet ./...`
- `go test ./...`（含 pkg/ws，需不再 flaky）
