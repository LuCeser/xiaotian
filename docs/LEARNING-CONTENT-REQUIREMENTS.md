## 目标与使用原则

产品关注英语与语文的默写、背诵和背默，管理对象是学习内容，不局限于英文单词。

家长提供材料和学习进度，系统负责识别、整理和教学辅助。首次使用应简单，不要求家长逐词录入、编写释义或例句，也不前置能力测评。

本次采用家长端导入页面。家长对话入口不属于本次方案；若以后采用，需要单独设计交互。

## 统一管理与内容结构

英语与语文共用导入、预览、管理和进度控制，通过学科与内容类型查找内容。是否使用筛选器或学科标签页，留给界面设计，不建设两套独立业务流程。

以下概念分别表达不同关系，不应混为单一分类：

| 概念 | 内容 |
| --- | --- |
| 学科 | 英语、语文 |
| 内容类型 | 单词／字词、短语、句子、古诗、课文段落等 |
| 练习方式 | 听写、背诵、背默 |
| 来源 | 具体教材及课次，或课外补充材料 |
| 练习范围 | 一个词条、整首古诗、整篇课文或指定段落 |

卡片可以是展示形式，但不能把所有内容都存成互不相关的单词或句子。

- 古诗保留标题、作者（如有）、完整原文、分行和顺序；当前按整首管理和练习。
- 课文保留完整原文及段落关系，支持整篇或指定段落。
- 指定段落可独立安排背默、记录掌握情况。掌握一个段落不代表掌握整篇；以后练习全文不要求重复导入。
- 高中长诗仅背默选段的场景暂不纳入本次范围，不据此增加本次交互复杂度。

## 导入与确认

1. 家长上传 PDF 扫描件或 PNG、JPEG 照片；可提前导入整本教材。
2. 系统识别材料中的学习内容，以及能从材料确定的教材版本、学段、年级、上下册、模块、单元和课次信息。
3. 按内容类型分组预览全部识别结果。词汇展示单词／短语、释义、所属课次；古诗和课文保留原文结构。
4. 家长勾选、纠错或批量调整，最后统一确认提交。识别结果不能跳过确认直接成为正式学习内容。

英语词汇导入默认只收录教材明确列出的单词、短语及对应释义，不把课文、练习题中出现的所有英文词自动当作词表。

语文材料可同时包含词语表、古诗、课文和练习题。识别结果按类型展示；明确标有背诵／默写要求的内容默认勾选，练习题不自动选入，其他正文允许整篇或按段勾选。保留英语词表的默认收录规则，不因缺少背诵标记而排除明确词表。

不要求家长提前裁图或拆分文件。手动调整用于纠错和选择，不应变成逐条补全属性的必经步骤。

## 教材归属与学习进度

- 材料能够识别出的教材信息自动填写，必要的缺失信息在首次建立教材时由家长确认或补充。
- 不同教材分别记录学习进度。
- 进度明确表达为“已学完第 N 课”：第 1 至 N 课可进入默写范围，第 N+1 课及以后不自动进入。
- 进入范围表示有资格被安排，不意味着下一次全部默写。实际练习安排仍需考虑复习计划。
- 明确属于教材但课次不确定的内容，在预览中标记待确认；支持对整页或多条内容统一指定课次，也允许家长明确选择加入默写范围。
- “没有课次”不等于“尚未学过”，不能将课外词汇一律排除。

## 补充内容与参与开关

不属于课程的词汇和其他补充材料保存在同一内容库中，保留来源，可按材料名称分组。其他教材若需跟随课次进度，作为另一教材管理；仅抽取一些词练习时，可作为补充词汇。

补充词汇提交后默认参与默写计划，除非家长明确移出。每个补充词汇提供“参与默写”开关，并支持批量调整。

关闭后保留内容及已有默写记录，但不再被自动选入；重新开启无需重新导入。不把移出计划等同于删除词汇。

## 释义、例句和难度适配

- 材料已有释义时保留原文释义，不要求家长重新编写。
- 英语词汇缺失释义时，系统依据教材语境和孩子水平补充，并标记为系统补充，与识别结果一起供家长确认。
- 例句按需生成，不在导入时批量生成。孩子询问含义或需要例句时，结合该词的教材释义和当时学习进度生成。
- 默认难度依据为教材版本、年级／学期与已学课次；地区和年级本身不足以代表孩子实际水平，不硬编码地区与能力的对应关系。
- 例句优先使用已学词汇与句式，避免用明显超出理解水平的句子解释生词。
- 适配能力由系统提供，首次使用不要求家长定义各年级能力标准或填写评估表；后续可以根据偏难或偏简单的反馈调整。
- 古诗、课文以材料原文为准，不套用英语释义、例句生成流程去替换原文。

## 重复导入与学习记录

- 同一页再次上传或同一词重复导入时自动合并，避免创建重复练习记录。
- 同一词保留多个来源、课次关联；任一所属课次已学完，就具有进入默写范围的资格。
- 合并时保留已有默写记录，不重新开始学习历史。
- 不同教材释义在预览中保留差异，供家长确认，不直接覆盖。
- 具体同词、多义词的存储和去重算法尚未决定；不得将以上规则简化成仅按词面覆盖所有内容。

## 后续验收应覆盖的场景

- 导入完整教材，确认后只允许已学课次进入自动计划。
- 混合页面包含词表、正文和练习题，能正确分组、选择，并保持原文结构。
- 释义有原文则保留、缺失则补充并标记；家长可批量调整课次后提交。
- 补充词汇默认参与，移出后不再自动选入，重新加入仍保留历史。
- 重复上传不重复创建记录；相同词的多个课次和释义差异不丢失。
- 古诗按整首练习；课文指定段落可以独立记录，且不被误算为全文掌握。
- 按需生成的英语例句符合当前教材语境和学习进度。
