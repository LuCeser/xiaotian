# #106 英语词组与整句报读

实施依据：[Issue #106](https://github.com/LuCeser/xiaotian/issues/106)，依赖已实现的 #104、#105。测试边界经用户确认：课堂 WebSocket，以及词库 HTTP API＋新课堂快照。

## 判定与限制

已核实 `database.Card`、`pybridge.DueCard` 与 `lesson.Word`：已有 `category` 可以可靠区分英语／语文，但没有词组／句子字段。例句非空和系统生成来源都不等同于目标内容类型，不能据此把完整句子改成词组。没有新增数据库类型字段或模型分类请求。

英语使用 `pkg/english.Classify` 的确定性保守判定，顺序如下：

1. 非英语字母内容沿用原行为，语文课堂在报读入口直接沿用原行为。
2. 含占位省略号且有英语字母：词组，沿用 #104 的固定片段停顿处理。
3. 去除判定用的缩写句点后，不足两个英语词：普通单词／缩写，沿用原模板。`sb.`、`sth.`、`Mr.`、`Mrs.`、`Ms.`、`Dr.`、`U.S.` 这类缩写的原文不会被删除。
4. 多词内容带正常句末标点，或命中有限主谓／疑问结构：按整句报读。主谓要求人称代词紧接助动词、系动词、有限常见谓语或缩约形式；疑问要求疑问词＋谓语或助动词＋人称代词；另识别 `there/this/that/these/those`＋系动词。孤立的 `do` 和宾语位置的 `you` 不作为句子证据。`Where is the library?`、`Where is the library`、`I like cats` 均提示写整句，保留原有问号等标点。
5. 命中有限词组集合：按词组报读。当前覆盖 `on the ground/first/second/third/top floor`、`ice cream`、`do homework`、`look after`、`take care`、`take care of`、`in front of`、`next to`、`be kind to`、`live near`，允许末尾 `sb.`／`sth.` 或宾格代词；空白和大小写只在判定副本中规范化。
6. 其余多词内容为歧义项：原文完整朗读，提示「请按原文写完整内容」，不附加例句。例如 `Tom likes cats`、`Open the door`。不凭空格数量断言词组。

这不是通用英语语法分析器：未列入的真实词组会保守降级；包含主谓结构的从句片段可能按句子提示，但写作目标仍是完整原文。新增可信词组结构需补充相应协议回归后扩展集合，不对未知内容宽泛猜测。添加时补例句仍保留 #105 的候选检查和模型排除完整句子的职责；本次额外在模型调用前排除已识别的无标点句子，歧义候选仍受原有模型提示和输出验证约束。

## 口头内容与进度

词组读目标固定部分，引用快照中可用的已存例句一次，提示「请写词组」。例句缺失或不可用时直接提示写词组，不生成。慢读重复目标两遍，例句一次；完整句子慢读重复整句，歧义内容重复完整原文；单词和独立缩写保留原有重读模板。首读、下一项、恢复、语音重读／慢读和按钮重读都经既有 `wordReadingText`。

仅改变口头表达；词库、课堂快照、核对目标和评分不改写。学生端沿用安全字幕、播放完成确认、计时和打断保护。报读及开课不补例句；孩子主动求助的按需例句能力继续遵循 ADR-0006。
