# 实时家教 Plan B：火山 RTC 混合编排

状态：**书面备用方案，未实现、未真机验收**。依据：[ADR-0002](adr/0002-browser-realtime-tutor.md) Accepted。当前主方案仍为自研实时交互＋MiMo，本文把切换动作写具体，不代表火山权限、账单或性能已经验证。

## 触发条件与记录

T0=2026-09-30，规划计时。2026-10-21 23:59（北京时间）仍无真 iPad 最小闭环，或 2026-11-11 23:59 RT-04/RT-05 任一不达标，**即开始切换**。第一周 2026-10-07 先检查并聚焦修复，不延后后两次日期。切换由当前执行者落实并写记录，不另起供应商选型讨论来延长自研。

记录触发日期、失败指标、设备/网络、原始样本、当前实现版本和未解决问题到 13-CHECKPOINTS.md。第六周响应/打断样本至少 30 次；缺少真实播放测量不能按达标处理。

## 接口与数据保留

- 浏览器仍是自然实时家教入口；用火山 Web RTC 接管媒体连接和实时对话编排，Go 服务签发短期会话授权，密钥留服务端。
- MiMo ASR/LLM/TTS 在火山允许的自定义接口中优先保留。逐项验证接口、区域、工具调用与取消能力；若整段 ASR 无法满足编排契约或延迟，替换对应模型适配器，记录原因；不得为了保留供应商而降低 RT 指标。
- Go/Python/SQLite、课堂 ID、业务工具及幂等执行继续使用。火山 Function Calling 回调转到同一工具执行服务，按钮也是同一路径。
- 媒体会话 ID 与课堂 ID 分开映射；切媒体服务不清空词库/成绩、不重复推进、不自动创建新课堂。
- 保留用户 HTTPS 证书、VPS 与真 iPad 验收环境；媒体服务器资源和费用单独记录。

## 切换顺序

1. **冻结继续扩展自研媒体。** 保留可运行实现和故障证据；仅修切换所需阻塞问题，停止无期限调优。默认入口接入配置显式切换到火山，不对学生暴露供应商术语。
2. **核验账户与接口。** 核对 RTC/语音 Agent 权限、目标区域、Web SDK 的目标 Safari 支持、自定义 ASR/TTS/LLM 接口、Function Calling、判停和打断。权限或接口不满足时记录为切换阻塞，继续处理接入；不能写成 Plan B 已完成。
3. **接真实工具。** 服务端发放会话授权；绑定 lesson_id 和课堂版本；先验证 get_lesson_state，再验证 advance_word 的唯一写入；重试返回原结果、旧版本冲突明确返回。单纯回声对话不算成环。
4. **迁移 3 词课堂。** 依次验证一次授权、至少 10 轮持续交流、上下文追问、书写等待、流式播放和打断。停播、取消、旧音频丢弃及真实已听内容必须在新编排下重验。
5. **比较同一组样本。** 同一 iPad/网络/教学场景至少 30 次测量；首问候≤3秒、响应P50≤1.5秒/P95≤2.5秒、打断P95≤500ms。后端收到音频不能代替实际开始播放；不得删慢样本，只能注明技术原因另测并保留原记录。
6. **恢复后续阶段。** 新媒体闭环通过后继续 Phase 14～16 的业务与产品验收。RT-01～RT-10 保持原阈值和未通过状态直至对应证据齐备。已触发 Plan B 时 Phase 16 不再强制补做已放弃的自研 pion 传输。

每一步在检查表记录负责人（当前执行者）、证据路径、结果和阻塞；每个后续执行会话先处理切换任务，不恢复旧媒体扩展。按钮可作为故障时备用，但必须明确降级，不能作为实时家教验收通过。

## 完成条件

切换不是最终验收。只有真机闭环、真实读写工具和响应/打断证据齐备，才能记录“Plan B 媒体闭环通过”；整个产品仍需 RT-01～RT-10 和 Phase 16 全量验收。

供应商能力参考来自 ADR 已列官方资料；实施时必须重新核对当前账户与接口契约，本文不承诺所有 MiMo 接口可直接接入。
