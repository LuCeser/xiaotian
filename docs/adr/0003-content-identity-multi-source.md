# ADR-0003：词条内容身份、多来源归属与释义差异处理

**Status:** Accepted（Issue #6 实施时拍板；随本任务落地并测试）
**Date:** 2026-10-13
**Deciders:** 项目用户（规格 US-31～35、US-45 与父规格实施决策已确认）；开发者执行技术设计

## Context

父规格（Issue #1）已确认：自动合并相同内容的重复导入，保留来源关系和既有学习历史；不同释义先展示差异供家长确认，不能以词面相同为由直接覆盖；精确的身份与多义词存储规则留给后续技术设计。Issue #6（重复导入保留多来源并确认释义差异）要求先定义稳定内容身份、来源关系和释义差异的兼容处理方式再实施，且已有词条标识与学习记录可继续读取。

现状（2026-10-13 核实）：

- `cards` 表 `UNIQUE(word, category)` 已是事实上的内容身份；`fsrs_card`、`review_logs` 挂在 card id 上。
- `card_assignments(card_id, textbook_id, lesson, include_in_scope)` 已支持一个词条挂多本教材（每本一个课次）——即「来源关系」的载体。
- 练习资格判定（Go `textbookScopePredicate` 与 Python `scope_predicate`）已是「任一归属的课次已学即入范围」的 OR 语义。
- 照片导入对相同词面不同释义只标记冲突、不可提交，家长无法确认处理。

## Decision

1. **稳定内容身份 = （词面去首尾空白, 学科）。** 沿用 `cards.UNIQUE(word, category)`，不引入新身份列、不改排序规则（大小写敏感、精确匹配）。词条 id 与其学习历史（FSRS 状态、review_logs）继续作为唯一锚点，任何导入路径不得重建。
2. **来源关系 = card_assignments 行。** 一行即一个来源（一本教材＋一个课次）；同一教材内一个词条只记一个课次（CONTEXT.md 归属定义）。重复导入对已有 (card, textbook) 走 upsert：课次以家长当次确认为准，`include_in_scope` 只增不减（导入永不清除家长已做的明确加入，见第 4 条）。
3. **释义差异兼容处理 = 单释义＋导入时显式确认。** `cards.meaning` 保持单值；相同词面不同释义的候选在提交前展示差异，家长二选一后处理：「保留词库释义」仅合并来源，「采用照片释义」经既有 edit 路径（`PUT /words/{id}`，不动 FSRS）更新释义后合并来源。未选择 = 待处理差异，不提交、不覆盖。不引入按来源存释义的多义存储。
4. **移出与组合规则。** 移出 = `participates = 0`（只取消自动安排资格，不删内容与历史）。导入路径（add/assign/edit）永不写 `participates`，家长明确的移出不能被重复导入静默重新开启；`include_in_scope = 1` 同理不被导入清除（前端 planAssignments 以提交后快照续存，纯函数保证）。资格 = `participates = 1` AND（无归属 OR 任一归属 include OR 任一归属课次已学）——两个开关与范围三者相与，Go/Python 两侧同形。

## Options Considered

### A：按来源存释义（card_assignments 加 meaning 列）——否决

课堂选题与解释需先解析「当前教材语境」才能选对释义，选题谓词、课堂快照、批改对照全部要带来源维度；1C1G 与当前单锚点模型下收益（同一词两本教材两个释义并存）缺乏已确认的产品故事支撑。若未来确有需求，从本 ADR 的显式确认记录起步演进，不推翻身份定义。

### B：引入规范化词面（小写/去变体）作身份——否决

改变 UNIQUE 语义即改变既有词条标识，与「已有词条标识与学习记录可继续读取」直接冲突；英语词表里 Apple/apple 是否同词应留给家长在确认环节判断，而不是引擎静默归并。

### C：冲突默认保留原释义并放行提交——否决

「默认保留」让差异在家长未确认时就随批提交，与「家长确认后处理」不符；待处理差异必须在回执中单独可见。

## Consequences

- 无破坏性迁移：既有库原样打开，身份、学习记录、归属全部继续可读（由 e2e 在预置旧数据的库上证明）。
- 「采用照片释义」后的课堂选题与解释自然使用确认后的释义（选题读 `cards.meaning`），AC 直证。
- 多义并存的诉求未来出现时，需要新 ADR 扩展来源级释义，并迁移确认记录。
- 导入回执按 新增／合并／待处理差异／失败 四类逐项报告，汇总以服务器实际响应拼装（批量添加结果的既有诚实边界）。
