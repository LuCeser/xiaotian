# ADR-0004：扫描 PDF 按页导入的拆页位置与执行方式

**Status:** Accepted（Issue #7 实施前拍板）
**Date:** 2026-10-14
**Deciders:** 项目用户（上限 40MB／100 页、四层测试缝确认）；开发者执行技术设计

## Context

Issue #7 要求扫描 PDF 按页识别、复用既有预览／编辑／确认流程、页级失败可单独重试、整本教材受控批量处理；父规格（Issue #1）明确把「扫描 PDF 处理、文件大小与页数限制、耗时任务状态及重试」留作本任务的技术决策。

现状（2026-10-14 核实）：

- 识别接口 `POST /api/v1/words/photo/recognize` 是一次一张图的无状态端点（单图上限 `photo.maxImageBytes` 默认 1MiB、PNG/JPEG 嗅探、既有错误码 envelope）；识别草稿完全在客户端，提交走统一 REST 入口（ADR-0003 的提交回执与重传保护）。
- 服务端没有任何任务／队列抽象；部署约束 1C1G／Go 服务 150MB 内存；仓库无 PDF 处理代码，构建禁 CGO（纯 Go 光栅化方案受限）。

## Decision

1. **拆页在浏览器端（pdf.js），服务端零改动。** pdf.js（Apache-2.0，固定版本、UMD 构建）随站点静态分发，在浏览器把 PDF 逐页渲染成 JPEG，逐页调用既有识别接口——与照片同一条请求路径，服务端单图上限与错误语义原样生效。不新增上传端点、不新增服务端任务状态、不引入轮询。
2. **执行方式 = 客户端顺序逐页。** 一次只渲染／编码一页（渲染 → canvas → 既有压缩阶梯 ≤768KiB → 释放）；文件大小上限 40MiB、页数上限 100，超限在加载时明确报错、不开始处理。100 页约数分钟，页级状态界面全程可见，可随时停止保留已完成页。
3. **页归属是预览层元数据。** 行携带 page 字段，预览按页分组（页头：页码＋状态＋本页课次批指定＋失败重试）；入库归属仍走 (textbook, lesson) assignment，ADR-0003 不变，无 schema 变更。
4. **不乱序、不重复 = 既有分类器跨页生效。** 各页结果按页序合并为一个行数组；`classifyPhotoEntries` 对全数组重跑，跨页同词自动标 invalid「与第 N 行重复」——单张照片内重复判定的既有语义自然延伸。重认某页 = 整页替换，不产生重复行。
5. **失败页处理。** 页级失败记录原因并继续后续页；已完成页结果保留；「重试该页」只重发该页。存在失败页时汇总明确显示，不伪称全文件成功。
6. **整本教材提交 = 自动分片。** 提交步骤把新增行按 100／批（既有 `maxEntries`）顺序提交、课次指定按 500／批（既有批量上限）分片，回执聚合各片的真实服务器响应。
7. **教材背景信息一次填写。** 教材 meta 取第一个成功页的识别结果，家长在既有教材面板确认／修改；课次可整页批量指定（亦可沿用全局批量工具栏）。

## Options Considered

### A：服务端拆页＋任务轮询接口——否决

需在 150MB 预算内安全解码 PDF（纯 Go 对扫描件常用编码覆盖不全，禁 CGO 排除 go-fitz）、新增任务状态与轮询端点、为暂存整册引入会话状态——与「服务端不留草稿状态」的既有设计相悖，工作量大数倍。

### B：要求家长把 PDF 拆成单页照片上传——否决

Issue #7 明确「无需拆文件」（US-2）。

### C：页归属落库（card_assignments 加 page 列）——否决

验收只要求预览与确认环节保留页码；来源 = assignment 行（ADR-0003），课堂范围判定与页码无关；加列是无产品故事支撑的 schema 扩张。

## Consequences

- 浏览器新增约 2MB 静态资源（pdf.js 主文件＋worker，`?v=` 缓存破坏，一次加载）；iPad Safari 实机检查（AC-7）为人工验收项。
- e2e 桩按页图字节注册固定响应：页图由浏览器 canvas 生成，字节确定性依赖固定的 Playwright／Chromium 版本；版本升级若致漂移，用捕获流程重录（mimo-stub 新增 `--save-unregistered` 落盘未注册图片）。mimo-stub 同时新增「先失败一次」夹具标记（`<name>.failonce`），支撑页级失败→重试成功的回归。
- 超限文件在客户端即被拒绝并说明原因；服务端单图上限继续作为每页请求的兜底。
- 100 页 × 每页一次视觉调用是「受控批量」的预期成本；进度 UI 承载家长等待体验。
- pdfjs-dist 以 devDependency 固定版本，构建产物复制进 `pkg/web/static/vendor/pdfjs/`（附带许可证文件），有同步脚本可重放。
