# Triage labels

| 技能角色 | 实际标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待评估 |
| needs-info | needs-info | 待补充信息 |
| ready-for-agent | ready-for-agent | 规格清晰，可交由 Agent 处理 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不处理 |

按技能指定角色使用上述实际标签。发布规格时应用 ready-for-agent；标签存在性应在写入前核实，不覆盖既有同名标签。
