# 家长端导入与词库交互评审

日期：2026-10-25（北京时间）。范围：本次已报告的导入、教材进度、词条展示与批量编辑、导入后不能默写问题。其他体验问题待实际使用中积累，单独处理。

## 已确认的业务含义

- “现在学到第 N 单元”更新并记住该教材教学进度，包含第 1～N 单元的词条，不表示立即开始默写。
- 上传新单元材料本身不更新进度。首次导入、识别到超出已知进度的内容时，可以由大模型结合上下文判断是否需要询问；沿用已有进度时不重复询问。确认需要融入重新设计的导入过程。
- 可以只把本次一批词条加入默写，教学进度不变。明确加入是持续决定，直到明确移出；何时自动复习由系统安排。
- 明确指定一个单元且未限制数量时，默写该单元全部可练词条，不限于到期词条。
- 指定默写的结果也更新后续复习安排；现有加练只记表现的行为不能直接作为这个需求的默认实现。

领域术语已同步到根目录 CONTEXT.md。本记录是设计输入，不代表上述交互能力已实现。

## 界面方向

用户在查看三个一次性原型后反馈：“看起来 A 比较合适。”采用 A 的并排核对布局作为后续规格基础：左侧材料预览与学习安排，右侧词条核对与批量编辑。B 的对话布局、C 的教材目录布局作为比较材料保留。

选择布局不代表已经逐项接受原型中的所有控件、文案或默认行为。原型没有接真实识别、大模型、保存、语音或复习算法。
