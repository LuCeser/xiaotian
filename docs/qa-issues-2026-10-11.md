## 1. 学科混默（语文与英语交替出题）

- 现象：词库同时录入了语文和英语后，默写流程里两个学科的词混在一起出题（两个英语、两个语文交替）。
- 期望：一次默写只默一个学科。例如今天先默英语，默完后再单独发起一次语文默写。

## 2. 口语确认未推进到下一个词

- 现象：默写中说"好了 / 下一个 / 好嘞"等确认语时，没有推进到下一个单词的默写，反而像是在回复上一句的话。
- 期望：这些确认语应推进到下一个单词的默写。
- 备注：不确定是之前某个阶段改错引入，还是其他原因。

## 3. 默写推进反应慢，疑似存在不必要的大模型调用

- 现象：默写推进（说"下一个"）反应明显偏慢。
- 期望：10 个词在开始时一次性选定；说"下一个"应立即去生成下一个词的音频，慢也只应慢在 TTS 合成，不应出现大模型调用的等待。
- 待确认：流程不应进入 agent loop（用户期望这是 workflow，不需要 agent loop）。
